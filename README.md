# DuPlast website

Initial live website build for **DuPlast (SMC-Private) Limited**.

This repository is intentionally structured as a simple static site so the brand, copy, product catalogue and company information can be iterated quickly. Contact, registration and final office details remain clearly marked for update.

## Pages
- Home
- Products
- Company
- Contact / RFQ preview

## Current verified profile inputs
- Founded: 2022
- Location: Karachi, Pakistan
- Business: polymer raw materials, masterbatches, polymer compounds, pigments and additives
- Leadership background: approximately a decade of polymer-industry experience across Bin Rasheed, Kompass Pakistan and LCI

## Preview status
The enquiry form is currently a front-end preview only and does not transmit submissions. Search-engine crawling is disabled in `robots.txt` while the site is being reviewed.
